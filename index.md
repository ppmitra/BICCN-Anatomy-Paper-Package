# BICCN Anatomy Package

The BICCN Anatomy Package is the result of a community effort to establish a standardized, comprehensive framework for understanding brain-wide cellular distribution and connectivity. To bridge the gap between massive raw repositories and accessible scientific analysis, this portal serves as a centralized hub offering direct links to thousands of diverse anatomical datasets, including single-neuron reconstructions, mesoscale tracing experiments, and transgenic volumetric brain images. By integrating extensive metadata spreadsheets alongside direct links to specialized external portals, interactive 3D web viewers, and open-source code repositories, the platform streamlines data discovery and empowers researchers worldwide to dynamically explore and analyze vertebrate neuroanatomy at unprecedented scale.
This paper package is linked to previous efforts of the: <a href="https://knowledge.brain-map.org/program/biccn" target="_blank">BRAIN Initiative Cell Census Network</a>

In this page you will find the following information:
- Links to package articles and brief descriptions of their contributions
- Comprehensive anatomical datasets and accompanying metadata
- Links to data portals and code for spatial registration of whole brain images
